## 1. 选题与系列
- **主线「钱包 + 时事」（2026-11-21 数据复盘后用户确认）**：钱包实用类（换汇、利率、税、年终奖、存钱）播放中位数 9,657 全账号最高，讲书 1,364、宏观热点 696 最低；两条爆款（5 万美元换汇 8.5 万、黄金第三回下 10.3 万）都是「政策/时事 + 卡在观众钱包上 + 一个带数字的为什么」。全文见 数据复盘/金融博物馆_改进计划_2026-11-21.md。
- 内容比例：钱包实用 + 时事解读 50%，生活经济学 30%，系列 / 金融史 / 讲书 20%。金融史当解释今天的工具，不再是主线。偏负面、离个人远的宏观热点（房价、恒大、芯片股）暂停，除非能落到「你的钱」上。
- 选题三问：最近发生了吗？跟观众自己的钱有关吗？能用一个带数字的反常识问题说出来吗？至少满足 2 条才做。
- 别太专业太垂直（2026-11-21 用户定）：抖音偏娱乐，机构层面的政策（外汇存款准备金率、回购再贷款等）不做；落到普通人日常碰得到的场景（刷卡、分期、年终奖、买金、存钱）。
- 接爆款：任何一条 24 小时内播放超过约 1 万，48 小时内补同方向续集。
- 合规：避开未证实的人物传闻、绯闻（会被限流或审核不过）；不荐股、不预测涨跌。
- **时长（2026-11-21）**：主版本 2:30–3:30（数据：不管多长，观众平均只看 25–50 秒）。超过 5 分钟只留给深度系列，每集必须能单独看懂。
- 系列别太多期：历史类 2–3 集；讲书按原理分（如经济学原理 7 期）。太长分上下半生成再拼接。
- 查资料多借鉴知乎好文章；打不开正文就请用户贴过来。数据必须查证并注出处。

## 2. 脚本与台词
- 主标题 ≤20 字。前 2–3 秒强 hook，直接抛问题引共鸣，不铺垫；多写候选挑最好。
- **开头硬性检查（2026-11-21，数据：2 秒跳出 41%、5 秒流失 40%）**：第 1 句必须含具体数字或反常识问题，第一句就要 hook 住人：抛一个非常反直觉的观察或跟观众有关的问题，参考伟大演讲者的开场手法（2026-11-23）；前 30 秒讲清「跟你的钱有什么关系」并留一个悬念（如「答案是一个数字」）；年份背景最早放到 30 秒之后。配音稿定稿前逐句过一遍前 30 秒。
- 中段每 30–40 秒换一次画面节奏（关卡切换、数据图、馆长出场），压住中段流失。
- 3 分钟主版本骨架：0–3 秒抛数字/问题 → 3–30 秒跟你的关系 + 悬念 → 30 秒–2:20 一条主线、案例 ≤3 → 2:20–2:50 揭晓 + 升华 → 2:50–3:10 二选一问题 + 片尾卡。
- 定一个 2–4 字锚词（不能和已用过的重复，查项目记忆列表）。
- 台词像朋友聊天：场景+数字开头，家常比方先于术语，不用四字书面词，结尾回到开头场景。
- 一个主角/母题物件贯穿，首尾呼应，转场不硬切。
- 自查抖音精选四条：获得感、惊喜感、表达力、感染力；要有差异化。
- 台词口吻（学芒格宝典，指南 9.12）：钩子＝具体场景＋两个数字，不设问腔、不报幕；先说出观众心里的话；原理用有名字的普通人小寓言；一个概念一个家常东西全片沿用；口语连接词（可、所以、就、其实），不用四字书面词和格言收尾；一句一口气 10–25 字，逗号只放换气处；数字说成人话（两千五百万、三成多）；不说绝对话；金句原样重复 3 次；写完大声念一遍。语速约每秒 4.9 字。

## 3. 配音（2026-11-19 起 Claude 用 AI 克隆用户声音直接生成，不再让用户录）
- 模型：Fun-CosyVoice3-0.5B（阿里开源，Apache-2.0 可商用），CPU 可跑，约 7 倍实时（4 分半配音约 30 分钟）。用户听过样音说「A 非常好」。
- 安装：云端环境启动脚本已预装到 /opt/cosyvoice（venv/、CosyVoice/、models/cv3/）。没有就照 GitHub 仓库 wyh060726edu-prog/- 的 skills/jinrong-museum-video/tools/setup_cosyvoice.sh 装一遍（约 10 分钟，要连 HuggingFace 和 GitHub）。
- 生成：`/opt/cosyvoice/venv/bin/python tools/cosyvoice_tts.py 台词.txt out/ --ref 参考音.wav --ref-text "参考音原话" --speed 1.15`。输出 voice.wav + voice.json（每句起止时间，直接做字幕），每句另存 lines/NNN.wav；某句不满意用 `--only 3,7` 只重做这几句。
- 参考音（默认用户本人）：/mnt/project-files/AI配音/ref_APEC前两句.wav，原话「今天上午，深圳，二十一个经济体的领导人拍了一张合影。每个人脖子上，都围着一条红色或者蓝色的围巾。」
- 换参考音：用户发一段 5–15 秒、干净无 bgm、只有一个人说话的录音，配上逐字一致的原话（不给就用 SenseVoice 转写后请用户核对），存到 AI配音/ 下并在项目记忆写明。用别人的声音必须先有本人授权；明星、公众人物、熟人的声音没授权不能克隆（侵犯声音权，抖音也会处理）。
- 台词写法：英文缩写写成中文或拆开（APEC → 亚太经合组织，或「A-P-E-C」），不然会念糊；多音字拿不准写拼音提示。
- 英文发音（2026-11-23）：别把 Claude、Anthropic 这类英文名写成「克劳德」式谐音让模型念，中文腔很重；能换中文说法就换，公司名、人名、工具名只上屏不念；实在要念就写英文原词，生成后用 ASR 回听。
- 生成后：SenseVoice 回听转写逐句比对台词，漏字、错字、念糊的句子用 --only 重做；语气柔和不激情；铺垫段 1.1–1.25 倍速，高潮和结尾 1.0。
- 在哪跑（2026-11-20 用户定）：默认云端后台跑（启动脚本已预装，生成时同时做画面，不耽误交付）；用户 Mac 本地只作备用（本地每期约省 15 分钟，但要用户多跑命令）。本地用法：用户一次性在终端粘贴 `curl -fsSL https://raw.githubusercontent.com/wyh060726edu-prog/-/main/skills/jinrong-museum-video/tools/install_mac.sh | bash` 装好；之后 Claude 交 `xxx_配音稿.txt`，用户下载到「下载」文件夹，终端输入 `peiyin`，把桌面「配音输出」里的 zip 发回来，Claude 解压后直接用 voice.wav + voice.json。参考音 ref_*.wav（加同名 .txt 写原话）放「下载」里，peiyin 自动换上。用户电脑连不上线程（组织要求受信任设备），Claude 不能远程跑。
- 用户已经录好的配音（如 APEC）照用原件，Claude 切句对齐（sherpa-onnx sense-voice）。
- 不用：F5-TTS、Fish Speech/OpenAudio、Spark-TTS（模型不可商用）；Kokoro 机器味重。

## 4B. 动效手法库（62 条样片，2026-11-16）
- 用户原意：不是照搬，是扩充表达手段；每支片按表现力挑最好的一招，能组合、改造、超越更好，质量第一。新样片放 视频制作学习/，从 L13 / P51 续编号补进文档。
- 写分镜时每句先问「这句要让观众感到什么」，查对照表选手法，分镜表加一列「手法编号」。
- 两套语法，一支片只选一种当主语法（另一种点缀），不同片轮换：
  - L 深度数据卡（硬数据、市场复盘、时事）：模糊压暗场景底 + 玻璃卡；图表按时间画出 → 停在关键点标注（竖虚线/红竖条/日期签/徽章）→ 约 3 秒卡片 3D 倾斜 8–12° 出结论大字；一张卡一个强调色，其余压到 35%；悬念顺序（局部再拉全景、最大块最后揭晓、先全淡再点红）。
  - P 像素闯关（原理课、讲书、故事）：每个概念翻译成人人玩过的游戏机制（推箱=规则、塔防=规则失灵、吃蘑菇=规模、俄罗斯方块=容量、排队=限流/挤兑、转圈=循环、Boss 血条=对手风险）；全片一条进度线（第几关→Boss→通关/失败→结算），HUD（命数/背包/血条）持续存在、首尾呼应；文字都是贴纸，颜色语义固定（黄说明、红章结论、绿成功、灰未解锁）；每 0.3–0.8 秒一个小动作，每段一个重拍。
- 常用对照（节选）：开场反常识 P01 印章砸屏；崩盘 P10 冰冻 GAME OVER / L04 红竖条；翻身 P11；量级大 P38 旋钮墙计数器；大数拆份 L06 树图；排名差距 L09；某年突变 L10；原始数据当证据 L11；连报占比 L12 数据牌一摞；回顾起落 P36；结尾投票 P37；求收藏 P48 存档点；求转发 P50。
- 音效分层（实测）：计数 tick 约 −40 dB 每 0.2–0.27 秒；普通动作 whoosh/blip/click −23~−30 dB；重拍（印章、大字、过关）−14~−20 dB，全片重拍 ≤3 个；同类动作同一音色。

## 4C. 连贯与画面密度（芒格宝典 / 普通人赢天才参考片，主要用于动画段）
- 一个世界几个固定舞台（≤6 个，每个写死一个含义，再出现时同机位开场）：先设计地图，结尾拉回全景总回顾；开场场景在结尾原样回收、灯光/物件状态反过来。
- 舞台内不切：换焦点靠镜头慢推拉 + 聚光灯（其余压暗 30–50%），没有完全静止的帧。
- 换场景用「引子」：同一物件飞到/滚到/变形到下一场景，或位置匹配切、剪影转场、像素溶解；不硬切不淡入淡出。分镜里给每个转场写明引子。
- 三条线贯穿：1 个主角（1P·你 或有名字的普通人）跟到最后；1–2 个母题物件每章变一次状态；一种游戏规则把概念翻成界面元素（字必须是正在念的词，不照抄游戏标志字样）。分镜每句写「主角在干什么 / 母题状态 / 界面变化」，三列全空就是断线。
- 每句一个画面变化（约每 2–3 秒）：名词出物件、动词出动作、数字出载体（日历、硬币堆、天平、仪表），卡在说到那个词的时刻。
- 字幕：底部一行，约画高 7%，白字粗黑描边+投影，不加底条；每句 1 个金色关键词。重点词三级：普通关键词静态金色；重点词（每 15–25 秒 1 个）念到才变色放大 + 细光扫过；全片最重要 1–2 句逐字卡拉 OK 走色。
- 配音流畅：句间停顿 0.12–0.25 秒，换章 ≤0.5 秒（MV 空镜段除外）；不为锚词收暗等重拍，高潮靠字幕特效和画面；boom 类全片 ≤3 个；切句在气口，拼接 15–25ms 交叉淡化。
- 画质密度：每个舞台是完整场景（纯空底 <30%，每屏 15–25 个物件、≥3 个持续环境小动作）；远中前三层景深 + 视差；一个主光源（光锥、光斑、投影、暗角）；像素色阶 3–5 级 + 纹理，不大面积单色块；每章一个主色调。

- 特效按事件选：新高 → 烟花 + 价格变金 +「见顶」签 + 放大镜气泡；破整数关口 → 横扫全屏的关口线 + 大字「跌破 200」或「站上 3000」；股灾或关键人物出事 → 闪电劈下来 + 碎玻璃 + 全屏闪白 + 色散；起爆 → 镜头放大近 3 倍跟着线头往上冲，加速度线、云层被冲散、火花尾迹、实时跳动的涨幅大字，再拉回全图。

- 同时套用小Lin说 L 系列：单日暴跌竖条加徽章（L04）、巨型半透明跌幅（L01）、事件钉在线上并配人物头像，出事时灰、回归时彩（L05）、多只股票同一时刻用九宫格分时一起跳、结尾数据牌一摞（L12）。
- 起爆前 0.3–0.4 秒把音乐压低再砸回，叠 boom、hit、timpani；重拍上加全屏震动、冲击缩放和红蓝色散。镜头跟线时别留大片空白，嫌长就缩短。
- 精髓：一条不断的线 + 永远在场的仪表台，线头每穿过一个有意义的价位或日期，就在重拍上「结算」一次（数字砸下、闪电、碎裂、整面墙变色、事件卡）；每 3–5 秒一次结算，最长 8 秒必须有新东西。
- 纳指/沪指片补充的手法（2026-11-24）：前高**水位线**（发光横线 +「还差 N 点」倒计，穿越时砸金字「解套 X 年 X 月」+「套牢 N 个交易日」）；低点**测量尺**（红竖线 + 实时 +x%）；HUD 参照点随牛熊换（熊市对比前高，牛市对比最近低点）；**地面墙**（同行或成分股方块铺成 3D 倾斜地板，整片变红/变绿 +「N 只里 M 只涨停」）；跌破关口三连（闪电 → 地面冲击环 → 白色大数字 +「较 X 最高 −Y%」）；危机**红暗角 + 边缘闪电裂纹框**；时代大标题配白光晕，后续事件卡往下叠；加息等次数用**圆点计数器** + 半透明大字「第七次」；「同一天」双事件卡；多日跌幅合并卡（「−10.47% · 3 个交易日」）。
- 配乐「憋气」：大事件前一拍让音乐下陷 6–14 dB，事件砸在下一拍（参考片每个音量下陷后都是大事件）。
- 结尾三拍：总收益大数字 → 换算成观众的钱（「1 万元 → 约 X 万元」）→ 公司墙从小到大滚动，穿过门槛线（「1 万亿以上 10 家 占 68.2%」），前十变市值条，压暗叠片名与数据来源。
- 我们的创新方向：线头旁常驻「你的 1 万元 → 现在 xx 元」钱包换算尺；事件卡做成博物馆铜牌展柜样式；日线无限放大到分时火箭；同一天三联卡；价格大字随强拍轻弹；对手方幽灵线 + 分化填色（L03）。
- 竖屏卡点片版式（v5 起）：HUD 从 y≈230 开始；事件卡、大号跌幅放 HUD 下方 y≈540 并加深色底；片头大字放屏幕中部加深色底带；K 线区 y 720–1290；九宫格和数据牌压在 x 70–890、y 230–1330。
- **每支片动手前，先把动效手法库、小Lin说 L 系列和本节过一遍，能用的都用上，别走老路。**

## 4A. 画面编排方法（FredTalk 财经 / 小Lin说 / 教程组件库，2026-11-18）
每期写完分镜都回到这一节和学习笔记，逐句看能不能用上库里的手法。主用财经风格、小Lin说风格、像素闯关风格；教程风格（白底紫色）只借基础手法，不照搬外观。

**核心原则**
- 不是「这句话配一个组件」，而是「这句话让观众看见哪个对象怎么变」。每句先写：对象 → 变化 → 证据在哪 → 观众看哪 → 交给谁。
- 动手前三问：关掉声音能看懂这段发生了什么吗？口播里每个名词、数字、动作画面上都看得见吗？这段的对象是接过上一段、又交给下一段的吗？答不上就先改设计。
- 一个组件只讲一件事，5–8 秒；主体 0.3 秒内出现，第 55–65% 处揭晓，结尾停稳 ≥1.2 秒。
- 先灰后亮：元素先灰着出现，讲到谁谁亮，讲过的变灰留在原位；一屏只有一个主角上色。
- 先留悬念再揭晓：???、打码、剪影、空位、问号卡，下一句揭晓。
- 数字放进容器（数字牌、账本卡、计数框、圆环）；同一指标变化时位置不动只换值；讲过的数字叠成一摞留着。
- 底图用真实画面压暗模糊（亮度 30–40%），前景卡片斜放微 3D 并持续轻微推近，不用纯色干背景。
- 证据要真：原文、报纸、公告逐句高亮 + 中文翻译 + 数字牌，标来源。
- 抽象概念做成生活比喻动画（汉堡分层、百元钞扣成本、天平、容器溢出）。
- 场景为本期重写，只拆组件的动作和对象关系；长段落用一条动作链（同一对象不断换角色）撑住。
- 章节导航：开头承诺几件事 / 问号拆解，章节卡，角落常驻问句，整期总图回来 3–5 次，结尾节点总结。

**交接与去重**
- 段与段之间不用淡入淡出、整屏平移：上一段末帧 = 下一段首帧，同一对象同位置同尺寸，一个连续动作交出去。写代码前列交接表（接缝｜上段末态｜下段首态｜动作｜音效）。
- 讲解结构类组件（路线图、问答、方法卡）全片只用一次；运镜套路也去重；章节页每期换着用。出关键帧前列一张全片组件表查重复，同一组件超过 3 次就换备选。

**动效参数（Remotion）**
- 每帧由 t=帧号/fps 算出，只改 transform / opacity / clipPath（少量 blur）；不用 CSS transition、keyframes、Math.random。
- 曲线：进入/落定 bezier(.22,1,.36,1)；搬移/缩放 smoothstep；擦出 bezier(.65,0,.2,1)；相机 quintic。入场默认无过冲，只有要「砸下来」才回弹一次。
- 先算终态版式再插值过去；同一进度驱动多个属性；对象连续变形不消失重现；用 clipPath 擦出代替淡入；逐字打出用透明占位不跳行。
- 单项进入 0.38–0.42 秒；项与项间隔按口播，无口播 0.5–1.2 秒不等距；同组小件错开 0.045–0.075 秒；相机移动 0.6 秒、停稳 0.85–1.65 秒、推近 1.3–1.6 倍。
- 退后 = 缩小 0.92–0.96 + 失焦 12–19px + 蒙版，同一进度；还要读的表格失焦 ≤4px。快切每段 0.2–0.8 秒。

**强调与排版底线**
- 指出某处：其余压暗到 0.6、阴影抬起、毛刷刷过；不用彩色框，少用黑框；高亮停到那句说完、≥1.5 秒。毛玻璃相邻几处别同一个样子。
- 关键内容 y ≤ 900（1080 画布）、左右 ≥80px；主体居中占 y 200–880，不上重下空；卡片逐张加入时每步整组重新居中。
- 一屏超过 4 块信息改成镜头逐块推近；一句大字停超 2 秒要带出第二个变化；推近不截字（左右留 24px）；会翻动的数字按最宽值留位。
- 口播提到的数量必须真实数字上屏；素材里没有的动作就重建示意，不放「相关的」视频凑数；能用真实画面就不用自绘示意。
