## 1. 选题与系列
- 日常反常识、『你』字开头的题流量好；3 分钟以上科普长片冲抖音精选。
- 系列别太多期：历史类 2–3 集；讲书按原理分（如经济学原理 7 期）。单集可加长，太长分上下半生成再拼接。
- 查资料多借鉴知乎好文章；打不开正文就请用户贴过来。数据必须查证并注出处。

## 2. 脚本与台词
- 主标题 ≤20 字。前 2–3 秒强 hook，直接抛问题引共鸣，不铺垫；多写候选挑最好。
- 定一个 2–4 字锚词（不能和已用过的重复，查项目记忆列表）。
- 台词像朋友聊天：场景+数字开头，家常比方先于术语，不用四字书面词，结尾回到开头场景。
- 一个主角/母题物件贯穿，首尾呼应，转场不硬切。
- 自查抖音精选四条：获得感、惊喜感、表达力、感染力；要有差异化。
- 台词口吻（学芒格宝典，指南 9.12）：钩子＝具体场景＋两个数字，不设问腔、不报幕；先说出观众心里的话；原理用有名字的普通人小寓言；一个概念一个家常东西全片沿用；口语连接词（可、所以、就、其实），不用四字书面词和格言收尾；一句一口气 10–25 字，逗号只放换气处；数字说成人话（两千五百万、三成多）；不说绝对话；金句原样重复 3 次；写完大声念一遍。语速约每秒 4.9 字。

## 3. 配音
- 输出逐句台词 txt（只放台词）。用户用剪映『文本朗读』录好上传，Claude 切句对齐（sherpa-onnx sense-voice）。
- 语气柔和不激情；铺垫段 1.1–1.25 倍速，高潮和结尾原速。注意英文词会不会被读错。

## 4. 画面
- 视觉风格不同质化：不要每支都是小人横着走；每支、系列每期换一种精致多彩的主风格。
- 场景丰富会动（灯光、烟、行人、招牌），用具体有意义的物件，不复用背景板，不用抽象漂浮图形。
- 每支片在章节交界穿插 2–4 段无旁白的空镜/场景动画（片名后、上下半交界、高潮前、片尾），只放音乐，bgm 在这几段抬高约 10 dB，像 MV（不要从头讲到尾）。
- 留白每段约 3 秒，长了有割裂感（2026-11-17）。每段必须有意义：放该章标志性地标（如香港＝汇丰总行、中银大厦、国金／维港；伦敦＝大本钟、塔桥），加地名大字＋年份＋一行点题；总览画面给每块场景贴名字。大字不压画面里其它文字，必要时加深色底框。
- 馆长要活：走动、转身、点头、换表情，手指随台词指向正在讲的那张卡/那个点（换句就换指向），不要只动嘴的立牌；封面每期换 pose；美国政治片不用馆长。
- 字幕大白字黑描边；任何文字不重叠、不被遮挡、不出画。
- 真实素材只用版权干净的（公有领域、可署名），不抓 YouTube 二创。素材站：Mixkit、Coverr、Internet Archive、Wikimedia Commons 可直接下；Pexels/Pixabay 网页有防机器人，只能走免费 API。电影片段有版权，不当免费素材。
- 画面不错乱（2026-10-30）：价签、数字、卡片等关键物件放最上层，不被别的物件挡、不挤进缝里；大字和卡片不出画；镜头推拉时元素不相撞穿插。抽帧要密：每个镜头抽开头/中间/结尾，进场退场途中也抽，逐张看完再交付。

## 4B. 动效手法库（62 条样片，2026-11-16）
- 用户原意：不是照搬，是扩充表达手段；每支片按表现力挑最好的一招，能组合、改造、超越更好，质量第一。新样片放 视频制作学习/，从 L13 / P51 续编号补进文档。
- 写分镜时每句先问「这句要让观众感到什么」，查对照表选手法，分镜表加一列「手法编号」。
- 两套语法，一支片只选一种当主语法（另一种点缀），不同片轮换：
  - L 深度数据卡（硬数据、市场复盘、时事）：模糊压暗场景底 + 玻璃卡；图表按时间画出 → 停在关键点标注（竖虚线/红竖条/日期签/徽章）→ 约 3 秒卡片 3D 倾斜 8–12° 出结论大字；一张卡一个强调色，其余压到 35%；悬念顺序（局部再拉全景、最大块最后揭晓、先全淡再点红）。
  - P 像素闯关（原理课、讲书、故事）：每个概念翻译成人人玩过的游戏机制（推箱=规则、塔防=规则失灵、吃蘑菇=规模、俄罗斯方块=容量、排队=限流/挤兑、转圈=循环、Boss 血条=对手风险）；全片一条进度线（第几关→Boss→通关/失败→结算），HUD（命数/背包/血条）持续存在、首尾呼应；文字都是贴纸，颜色语义固定（黄说明、红章结论、绿成功、灰未解锁）；每 0.3–0.8 秒一个小动作，每段一个重拍。
- 常用对照（节选）：开场反常识 P01 印章砸屏；崩盘 P10 冰冻 GAME OVER / L04 红竖条；翻身 P11；量级大 P38 旋钮墙计数器；大数拆份 L06 树图；排名差距 L09；某年突变 L10；原始数据当证据 L11；连报占比 L12 数据牌一摞；回顾起落 P36；结尾投票 P37；求收藏 P48 存档点；求转发 P50。
- 音效分层（实测）：计数 tick 约 −40 dB 每 0.2–0.27 秒；普通动作 whoosh/blip/click −23~−30 dB；重拍（印章、大字、过关）−14~−20 dB，全片重拍 ≤3 个；同类动作同一音色。
- 我们的升级：数据卡做成博物馆展柜（倾斜=灯扫过、大字=铜牌）；进度线换成逛博物馆（楼层图、本展厅参观完成盖馆章、收藏柜）；馆长站在卡前用手指点；每张卡注出处日期。不照抄 FredTalk 名字、角色、英文字样，不用真人照片和公司 logo。

## 4C. 连贯与画面密度（芒格宝典 / 普通人赢天才参考片）
- 一个世界几个固定舞台（≤6 个，每个写死一个含义，再出现时同机位开场）：先设计地图，结尾拉回全景总回顾；开场场景在结尾原样回收、灯光/物件状态反过来。
- 舞台内不切：换焦点靠镜头慢推拉 + 聚光灯（其余压暗 30–50%），没有完全静止的帧。
- 换场景用「引子」：同一物件飞到/滚到/变形到下一场景，或位置匹配切、剪影转场、像素溶解；不硬切不淡入淡出。分镜里给每个转场写明引子。
- 三条线贯穿：1 个主角（1P·你 或有名字的普通人）跟到最后；1–2 个母题物件每章变一次状态；一种游戏规则把概念翻成界面元素（字必须是正在念的词，不照抄游戏标志字样）。分镜每句写「主角在干什么 / 母题状态 / 界面变化」，三列全空就是断线。
- 每句一个画面变化（约每 2–3 秒）：名词出物件、动词出动作、数字出载体（日历、硬币堆、天平、仪表），卡在说到那个词的时刻。
- 字幕：底部一行，约画高 7%，白字粗黑描边+投影，不加底条；每句 1 个金色关键词。重点词三级：普通关键词静态金色；重点词（每 15–25 秒 1 个）念到才变色放大 + 细光扫过；全片最重要 1–2 句逐字卡拉 OK 走色。
- 配音流畅：句间停顿 0.12–0.25 秒，换章 ≤0.5 秒（MV 空镜段除外）；不为锚词收暗等重拍，高潮靠字幕特效和画面；boom 类全片 ≤3 个；切句在气口，拼接 15–25ms 交叉淡化。
- 画质密度：每个舞台是完整场景（纯空底 <30%，每屏 15–25 个物件、≥3 个持续环境小动作）；远中前三层景深 + 视差；一个主光源（光锥、光斑、投影、暗角）；像素色阶 3–5 级 + 纹理，不大面积单色块；每章一个主色调。

## 4A. 画面编排方法（FredTalk 财经 / 小Lin说 / 教程组件库，2026-11-18）
每期写完分镜都回到这一节和学习笔记，逐句看能不能用上库里的手法。主用财经风格、小Lin说风格、像素闯关风格；教程风格（白底紫色）只借基础手法，不照搬外观。

**核心原则**
- 不是「这句话配一个组件」，而是「这句话让观众看见哪个对象怎么变」。每句先写：对象 → 变化 → 证据在哪 → 观众看哪 → 交给谁。
- 动手前三问：关掉声音能看懂这段发生了什么吗？口播里每个名词、数字、动作画面上都看得见吗？这段的对象是接过上一段、又交给下一段的吗？答不上就先改设计。
- 一个组件只讲一件事，5–8 秒；主体 0.3 秒内出现，第 55–65% 处揭晓，结尾停稳 ≥1.2 秒。
- 先灰后亮：元素先灰着出现，讲到谁谁亮，讲过的变灰留在原位；一屏只有一个主角上色。
- 先留悬念再揭晓：???、打码、剪影、空位、问号卡，下一句揭晓。
- 数字放进容器（数字牌、账本卡、计数框、圆环）；同一指标变化时位置不动只换值；讲过的数字叠成一摞留着。
- 底图用真实画面压暗模糊（亮度 30–40%），前景卡片斜放微 3D 并持续轻微推近，不用纯色干背景。
- 证据要真：原文、报纸、公告逐句高亮 + 中文翻译 + 数字牌，标来源。
- 抽象概念做成生活比喻动画（汉堡分层、百元钞扣成本、天平、容器溢出）。
- 场景为本期重写，只拆组件的动作和对象关系；长段落用一条动作链（同一对象不断换角色）撑住。
- 章节导航：开头承诺几件事 / 问号拆解，章节卡，角落常驻问句，整期总图回来 3–5 次，结尾节点总结。

**交接与去重**
- 段与段之间不用淡入淡出、整屏平移：上一段末帧 = 下一段首帧，同一对象同位置同尺寸，一个连续动作交出去。写代码前列交接表（接缝｜上段末态｜下段首态｜动作｜音效）。
- 讲解结构类组件（路线图、问答、方法卡）全片只用一次；运镜套路也去重；章节页每期换着用。出关键帧前列一张全片组件表查重复，同一组件超过 3 次就换备选。

**动效参数（Remotion）**
- 每帧由 t=帧号/fps 算出，只改 transform / opacity / clipPath（少量 blur）；不用 CSS transition、keyframes、Math.random。
- 曲线：进入/落定 bezier(.22,1,.36,1)；搬移/缩放 smoothstep；擦出 bezier(.65,0,.2,1)；相机 quintic。入场默认无过冲，只有要「砸下来」才回弹一次。
- 先算终态版式再插值过去；同一进度驱动多个属性；对象连续变形不消失重现；用 clipPath 擦出代替淡入；逐字打出用透明占位不跳行。
- 单项进入 0.38–0.42 秒；项与项间隔按口播，无口播 0.5–1.2 秒不等距；同组小件错开 0.045–0.075 秒；相机移动 0.6 秒、停稳 0.85–1.65 秒、推近 1.3–1.6 倍。
- 退后 = 缩小 0.92–0.96 + 失焦 12–19px + 蒙版，同一进度；还要读的表格失焦 ≤4px。快切每段 0.2–0.8 秒。

**强调与排版底线**
- 指出某处：其余压暗到 0.6、阴影抬起、毛刷刷过；不用彩色框，少用黑框；高亮停到那句说完、≥1.5 秒。毛玻璃相邻几处别同一个样子。
- 关键内容 y ≤ 900（1080 画布）、左右 ≥80px；主体居中占 y 200–880，不上重下空；卡片逐张加入时每步整组重新居中。
- 一屏超过 4 块信息改成镜头逐块推近；一句大字停超 2 秒要带出第二个变化；推近不截字（左右留 24px）；会翻动的数字按最宽值留位。
- 口播提到的数量必须真实数字上屏；素材里没有的动作就重建示意，不放「相关的」视频凑数；能用真实画面就不用自绘示意。
