## 1. 选题与系列
- 日常反常识、『你』字开头的题流量好；3 分钟以上科普长片冲抖音精选。
- 系列别太多期：历史类 2–3 集；讲书按原理分（如经济学原理 7 期）。单集可加长，太长分上下半生成再拼接。
- 查资料多借鉴知乎好文章；打不开正文就请用户贴过来。数据必须查证并注出处。

## 2. 脚本与台词
- 主标题 ≤20 字。前 2–3 秒强 hook，直接抛问题引共鸣，不铺垫；多写候选挑最好。
- 定一个 2–4 字锚词（不能和已用过的重复，查项目记忆列表）。
- 台词像朋友聊天：场景+数字开头，家常比方先于术语，不用四字书面词，结尾回到开头场景。
- 一个主角/母题物件贯穿，首尾呼应，转场不硬切。
- 自查抖音精选四条：获得感、惊喜感、表达力、感染力；要有差异化。

## 3. 配音
- 输出逐句台词 txt（只放台词）。用户用剪映『文本朗读』录好上传，Claude 切句对齐（sherpa-onnx sense-voice）。
- 语气柔和不激情；铺垫段 1.1–1.25 倍速，高潮和结尾原速。注意英文词会不会被读错。

## 4. 画面
- **主风格按题材分（2026-11-19 用户定）：具象题材（城市、国家、历史、峰会、人物事件，如香港、新加坡、APEC）学小Lin说，以真实影像资料为主，体现繁荣和变化；抽象题材（原理、流程、制度，如中国税制、经济学原理）以 Remotion 动画讲解为主。同一片里也按段落分：讲抽象机制用动画，讲具体场景用实拍。用户不露脸。素材必须和正在讲的内容精确匹配（如讲香港回归就放交接仪式、升降旗的真实画面），不能随便放一段相关素材。数据呈现要真正用上第 4A 节和 GitHub 库里学到的手法。动手前先看几支小Lin说的视频。**
- 开工先读用户 GitHub 上的视频 skills 库（FredTalk、claude-remotion-skill、huashu-art-motion、hyperframes、OpenMontage、lemo-opuscar、pixelfx、video-shotcraft），里面的方法和素材都要用起来（2026-11-19）。
- 必须用动画的场景要写实精细（2026-11-19）：银行、商店、冰室、糖水店不能用色块加文字标签代替；真实地标按真实造型画（如汇丰总行大厦），有品牌的楼画上标志；交付前抽帧查，不看字也能认出是哪里。
- 视觉风格不同质化：不要每支都是小人横着走；每支、系列每期换一种精致多彩的主风格。
- 场景丰富会动（灯光、烟、行人、招牌），用具体有意义的物件，不复用背景板，不用抽象漂浮图形。
- 每支片穿插几段无旁白的空镜/场景动画，只放音乐，像 MV（不要从头讲到尾）。
- 留白长短看画面动静（2026-11-18）：画面一直在变（实拍、镜头推移、灯光行人在动）留 2–3 秒；画面基本固定不动只留约 1 秒，3–4 秒就显长、有割裂感。每段必须有意义：放该章标志性地标（如香港＝汇丰总行、中银大厦、国金／维港；伦敦＝大本钟、塔桥），加地名大字＋年份＋一行点题；总览画面给每块场景贴名字。大字不压画面里其它文字，必要时加深色底框。
- 馆长要活：走动、手势、指向正在讲的元素；美国政治片不用馆长。
- 字幕大白字黑描边；任何文字不重叠、不被遮挡、不出画。
- 真实素材只用版权干净的（公有领域、可署名），不抓 YouTube 二创。

## 4A. 画面编排方法（FredTalk 财经 / 小Lin说 / 教程组件库，2026-11-18）
每期写完分镜都回到这一节和学习笔记，逐句看能不能用上库里的手法。主用财经风格、小Lin说风格、像素闯关风格；教程风格（白底紫色）只借基础手法，不照搬外观。

**核心原则**
- 不是「这句话配一个组件」，而是「这句话让观众看见哪个对象怎么变」。每句先写：对象 → 变化 → 证据在哪 → 观众看哪 → 交给谁。
- 动手前三问：关掉声音能看懂这段发生了什么吗？口播里每个名词、数字、动作画面上都看得见吗？这段的对象是接过上一段、又交给下一段的吗？答不上就先改设计。
- 一个组件只讲一件事，5–8 秒；主体 0.3 秒内出现，第 55–65% 处揭晓，结尾停稳 ≥1.2 秒。
- 先灰后亮：元素先灰着出现，讲到谁谁亮，讲过的变灰留在原位；一屏只有一个主角上色。
- 先留悬念再揭晓：???、打码、剪影、空位、问号卡，下一句揭晓。
- 数字放进容器（数字牌、账本卡、计数框、圆环）；同一指标变化时位置不动只换值；讲过的数字叠成一摞留着。
- 底图用真实画面压暗模糊（亮度 30–40%），前景卡片斜放微 3D 并持续轻微推近，不用纯色干背景。
- 证据要真：原文、报纸、公告逐句高亮 + 中文翻译 + 数字牌，标来源。
- 抽象概念做成生活比喻动画（汉堡分层、百元钞扣成本、天平、容器溢出）。
- 场景为本期重写，只拆组件的动作和对象关系；长段落用一条动作链（同一对象不断换角色）撑住。
- 章节导航：开头承诺几件事 / 问号拆解，章节卡，角落常驻问句，整期总图回来 3–5 次，结尾节点总结。

**交接与去重**
- 段与段之间不用淡入淡出、整屏平移：上一段末帧 = 下一段首帧，同一对象同位置同尺寸，一个连续动作交出去。写代码前列交接表（接缝｜上段末态｜下段首态｜动作｜音效）。
- 讲解结构类组件（路线图、问答、方法卡）全片只用一次；运镜套路也去重；章节页每期换着用。出关键帧前列一张全片组件表查重复，同一组件超过 3 次就换备选。

**动效参数（Remotion）**
- 每帧由 t=帧号/fps 算出，只改 transform / opacity / clipPath（少量 blur）；不用 CSS transition、keyframes、Math.random。
- 曲线：进入/落定 bezier(.22,1,.36,1)；搬移/缩放 smoothstep；擦出 bezier(.65,0,.2,1)；相机 quintic。入场默认无过冲，只有要「砸下来」才回弹一次。
- 先算终态版式再插值过去；同一进度驱动多个属性；对象连续变形不消失重现；用 clipPath 擦出代替淡入；逐字打出用透明占位不跳行。
- 单项进入 0.38–0.42 秒；项与项间隔按口播，无口播 0.5–1.2 秒不等距；同组小件错开 0.045–0.075 秒；相机移动 0.6 秒、停稳 0.85–1.65 秒、推近 1.3–1.6 倍。
- 退后 = 缩小 0.92–0.96 + 失焦 12–19px + 蒙版，同一进度；还要读的表格失焦 ≤4px。快切每段 0.2–0.8 秒。

**强调与排版底线**
- 指出某处：其余压暗到 0.6、阴影抬起、毛刷刷过；不用彩色框，少用黑框；高亮停到那句说完、≥1.5 秒。毛玻璃相邻几处别同一个样子。
- 关键内容 y ≤ 900（1080 画布）、左右 ≥80px；主体居中占 y 200–880，不上重下空；卡片逐张加入时每步整组重新居中。
- 一屏超过 4 块信息改成镜头逐块推近；一句大字停超 2 秒要带出第二个变化；推近不截字（左右留 24px）；会翻动的数字按最宽值留位。
- 口播提到的数量必须真实数字上屏；素材里没有的动作就重建示意，不放「相关的」视频凑数；能用真实画面就不用自绘示意。

**台词 → 组件速查（编号见学习笔记）**

- 讲几件事：H025 三件事承诺 / H029 问号拆解 / H004 三段目录。
- 章节：H001 巨号描边、H110 照片章节卡、H009 地图推进（换地点）、H011 人物章节、H012 倒计（最后一章）、L47 阶段卡；教程风 20 种章节过渡轮换。

**音效（和第 5 节合并，第 5 节优先）**
- 一个主动作一声，挂在动作开始或落定那帧：出现 pop、推近接管 woosh、遮罩刷出短 whoosh、让位展开 slide、点击 click、打字只覆盖打字区间；「叮」和数字滚动声全片各 1–2 处。

**风格提醒**
- A 股/港股题材红涨绿跌；小Lin/Fred 的「红=跌」是美股习惯，要反过来。
- 不照搬 FredTalk 的白底紫色或黑金作为固定外观；每期仍按第 4 节换一种主风格，只沿用方法和参数。

## 5. 声音与 bgm
- 全片 1–3 首不穿插：开头柔和，高潮换一首；人声段 bgm 低于人声 18–20 dB；同一秒最多 1 个音效；成片 −14 LUFS。
- 曲库：bgm/通用/（默认首选）、bgm/ES/（Epidemic Sound，缺曲列曲名请用户下载）。
- 别用：Windy Hill、Time、Victory、Star Sky、Merry Christmas Mr. Lawrence、Going Up、Monkeys Spinning Monkeys、Summer、Sneaky Snitch。要抒情不燃，不要电子抽象风。带人声商业歌可多给一版无歌。

## 6. 流程节点
1. 选题+分期 → 2. 脚本+逐句台词 txt → 2.5 逐句动作表（对象→变化→证据→看哪→交给谁）+ 按第 4A 节速查表给每句选组件 + 段间交接表 + 全片组件去重表 → 3. 等用户录音 → 4. 先做试片（新画风）等确认 → 5. 逐段渲染 → 6. 合成整片 → 7. 抽帧逐一检查文字与画面、测响度，并过第 4A 节自检：关声音能看懂吗、名词数字都上屏了吗、有没有慢推/定格凑时长、组件有没有重复、强调有没有用框、排版居中且 y≤900、推近后字完整、接缝前后 0.5 秒动态顺不顺 → 8. 交付。

## 7. 交付
- 成片 + 简介 + 标题 + tag + 封面（像素馆长模板，每期换 pose）；合集封面 1080×1080。
- 每期封面出两版：竖封面 1080×1920 + 横封面 1920×1080（2026-11-18 用户定）。

## 新项目工作流（2026-11-18 用户定，严格按顺序）
1. 先写全系列脚本规划。
2. 资料能自己搜就自己搜；打不开的（如知乎正文）和要用的 BGM，列成一张「需要你提供」清单给用户。**等用户发来之前不写配音文案。**
3. 先规划每段配什么真实画面素材、配乐怎么放（2026-11-19：不要被配音稿牵着走，配音是最后一公里）。
3.5 最后再一次性给全系列所有配音文案，脚本文案一次定稿，之后不再改。
4. 用户统一录好配音发来。
5. 一期一期做，每期交付让用户及时纠正。
- 能自己做的尽量自己做：知乎文章打不开时，先按同标题、同作者去搜转载（公众号、今日头条、个人博客），实在找不到又必须要，再请用户复制正文。
- 每支片都去免费素材网站找真实视频素材做空镜（比如香港 90 年代的霓虹灯、老电影感的街景），只用能合法使用的，片尾注明来源（2026-11-18 用户定）。
- 列出所用曲名和作者，简介里署名。
